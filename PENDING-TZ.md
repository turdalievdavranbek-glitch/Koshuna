# Koshuna — ТЗ пакет (Grok, 2026-09-13)

Продолжение с `cursor/tiles-internal-branch-7ac8`. Модель: Grok. Один APK.

## Сделано в этом пакете
1. Кружки = видеообъявления, рейтинг лайки+комменты, только выбранный регион КР (сброс кэша при смене, напр. Чуй), ~раз в час, название под кружком, до 10, свайп, статично под поиском, подпись «Самые залайканные объявления от соседей»
2. «Базар сегодня» и «Еда рядом» сразу под кружками; слоган-карточка с главной убрана
3. Базар: нет «Все точки» / «Все категории»; быстрое объявление в кабинете
4. Фильтры покупателя = таксономия продавца (без чипа «Все категории»)
5. Пост: микрофон после тихого видео → транскрипт (цену ИИ не выдумывает); текст вручную без видео/голоса; сломанный Instagram-текст убран; «Назад» сразу на главную
6. Карточки Магазин / Прилавок / Кафе / Застройщик / Автосалон: медиа → имя → адрес/гео → категория → цена; −% на акциях в ленте; без «от соседа» на бизнесе
7. Блоки доверия только у личных вещей
8. Лайк/дизлайк снимаются повторным тапом
9. «Свежее в вашем районе»: один горизонтальный ряд, мелкий шрифт
10. Своя страница — только свои объявления
11. Поделиться объявлением ссылкой
12. Android: `ACCESS_FINE_LOCATION` + `ACCESS_COARSE_LOCATION` + runtime + WebView geolocation
