# Koshuna — незаконченные ТЗ (пауза 2026-09-12/13)

Список того, что Давранбек просил, но пакет остановили из‑за лимита Cursor.
Продолжать с ветки `cursor/tiles-internal-branch-7ac8`. Модель: Grok. Один APK в конце пакета.

## Уже было в рабочей версии (кратко)
- Закреплённое нижнее меню, пересъём видео, камера как у базара
- Заметная геолокация, водяной знак, добросовестность, общая лента
- APK через туннель, вход: телефон + код `123456`
- Часть правок кружков/лайков/слогана могла частично попасть в ветку — сверить по факту на телефоне

## Осталось сделать

### Главная / кружки
1. Кружки = реальные видеообъявления (не заглушка)
2. Отбор по лайкам/комментариям
3. Только выбранный регион КР; при смене региона (например Чуй) — сразу только этот регион
4. Обновление кружков примерно раз в час
5. Под кружком видно **название товара** (+ локация/цена)
6. До **10** кружков, свайп вправо
7. Кружки **статично** под поиском (не уезжают со скроллом)
8. Подпись под кружками: «Самые залайканные объявления от соседей»
9. Блоки «Базар сегодня» и «Еда рядом» — **ниже** кружков
10. Убрать слоган-карточку «От соседа» с главной полностью

### Базар / фильтры
11. Убрать кнопки «Все точки» и «Все категории»
12. Одинаковые фильтры у продавца и покупателя
13. В «Свежее в вашем районе» — подробный, интуитивный фильтр: один ряд, мелкий шрифт

### Создание объявления
14. После видео — микрофон, если сняли без звука; ИИ → текст (цены не выдумывать)
15. Можно написать текст вручную без голоса и без видео
16. Убрать сломанный «текст как в Instagram»
17. «Назад» без публикации не лагает и возвращает в главное меню
18. «Быстрое объявление» перенести в **личный кабинет**

### Карточки продавцов
19. Простые карточки: **Магазин**, **Прилавок**, **Кафе**, **Застройщик**, **Автосалон**
20. Минимум: фото/видео/текст → название → адрес/гео → категория → цена
21. Акции на конкретные товары с бейджем **−%** на карточке
22. Всё попадает в единую домашнюю ленту

### Доверие / профиль / шаринг
23. Блоки «Оплата после встречи», «От соседа», «Еду смотреть», «Голос хозяина» — только для **личных вещей** (не дом/бизнес)
24. Лайк и дизлайк снимаются повторным тапом
25. На своей странице — только свои объявления (чужие убрать)
26. Поделиться **ссылкой** на каждое объявление

### Android / Capacitor
31. В AndroidManifest добавить разрешения геолокации: `ACCESS_FINE_LOCATION` и `ACCESS_COARSE_LOCATION` (и нужный runtime-запрос), иначе гиперлокальные фичи («рядом», авто-определение района) не работают через настоящий GPS.

### Потом (инфраструктура)
27. Свой сервер вместо trycloudflare
28. Настоящий SMS/WhatsApp/Telegram OTP
29. Данные не только в localStorage
30. Подпись Play Store + юридические страницы
