# Кошуна — nested tiles marketplace

Preview restore of the Koshuna classifieds app with nested section tiles (Авто drill-down), favorites, `/post`, and `lib/store.tsx`.

This is **not** the Capacitor category-tree APK that only shows Вещи / Услуги / Гостиницы.

## Run

```bash
npm install
npm run dev
```

Dev server: http://localhost:43123

## Login

Any Kyrgyz phone number + SMS code `123456`.
