# Konshu — приложение для телефона

**Konshu** — это «доска объявлений» для Кыргызстана: квартиры, секонд-хенд, животные, авто, отели, услуги, вакансии и стройматериалы.

Это рабочая версия по макетам из ТЗ. Её можно открыть в браузере телефона (Android и iPhone) как обычное приложение. Данные учебные: цены и объявления — примеры, не настоящие предложения.

## Как открыть у себя на компьютере

Нужна программа Node.js (версия 20 или новее).

1. Скачайте папку проекта.
2. Откройте её в терминале и выполните:

```bash
npm install
npm run dev
```

3. Откройте в браузере: [http://127.0.0.1:43123](http://127.0.0.1:43123)

На компьютере приложение выглядит как экран телефона. На настоящем телефоне займет весь экран.

## Что уже умеет

- Смотреть ленту и девять разделов **без входа**
- Искать и фильтровать (город, цена, комнаты, «только с фото»)
- Открывать карточку квартиры и товара
- Смотреть объявления на карте
- Входить по номеру телефона (для проверки подойдёт любой SMS-код, например `123456`)
- Добавлять в избранное, писать в чат, звонить / WhatsApp / Telegram
- Размещать объявление в три шага
- Переключать язык: русский, кыргызский, английский
- Сохранять выбранный город и избранное на этом устройстве

Вход нужен только чтобы разместить объявление, написать владельцу, сохранить поиск или добавить в избранное.

Сейчас это веб-приложение — его можно сразу открыть с телефона. Чтобы оно появилось в магазинах приложений, позже его упаковывают в «обёртку» для Android и iOS (это отдельный шаг: иконка, аккаунты разработчика, проверка магазинов). Дизайн уже общий для обеих систем.
